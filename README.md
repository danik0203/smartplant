# SmartPlant 🌿 - המשתלה הביתית (PWA & Mobile Ready)

אפליקציית Web/PWA מודרנית, מהירה ומותאמת לנייד בעברית מלאה (RTL), לניהול השקיה חכם של צמחי הבית, מעקב אחרי סוג הקרקע, התאורה והבריאות של כל צמח, עם **זיהוי צמחים אוטומטי ורופא צמחים מבוסס Gemini Vision AI**.

---

## ✨ פיצ'רים עיקריים

- **📸 הוספת צמח אוטומטית בצילום (AI Vision)**: צלמו את הצמח וה-AI יזהה את סוג הצמח, ימליץ על תדירות ההשקיה וכמות המים במ"ל, יגדיר את סוג הקרקע והתאורה המתאימים, יבדוק אם יש בעיות בעלים וייצר רשימת המלצות מותאמת אישית לבית.
- **✍️ הזנה ידנית וקטלוג צמחי בית מובנה**: אפשרות להזנה ידנית מלאה או בחירה בלחיצה אחת מתוך קטלוג צמחים נפוצים בישראל (מונסטרה, סנסיווריה, פותוס, פיקוס כינורי, ספטיפיליום, קלתאה ועוד).
- **💧 דשבורד "השקיה היום" חכם**:
  - זיהוי צמחים שצמאים היום או באיחור.
  - כפתור **"השקיתי עכשיו! 💧"** בלחיצה אחת (עם חגיגת קונפטי ותיעוד מי השקה).
  - כפתור **"האדמה לחה (דחה ביומיים) ⏳"** למניעת השקיית יתר וריקבון שורשים.
  - מעקב משלים אחרי **ריסוס לחות (💦)** ו**דישון תקופתי (🌱)**.
- **🩺 רופא הצמחים AI**: צילום עלים מצהיבים, כתמים או קרקע חשודה לקבלת אבחון בוטני מדויק, שלבי טיפול והבראה, ועדכון אוטומטי של תוכנית ההשקיה של הצמח בלחיצה.
- **💬 תזכורות השקיה בוואטסאפ לבני הבית/שותפים**: יצירת הודעת סיכום מעוצבת עם הצמחים שצמאים היום וכמויות המים המומלצות.
- **☁️ סנכרון רב-מכשירים (Supabase + LocalStorage)**: עובדת מיד מהקופסה עם שמירה מקומית וסנכרון ענן בזמן אמת בין מכשירים.
- **📱 מוכנה לחנויות האפליקציות (App Store / Google Play)**: כוללת הגדרות `capacitor.config.json` ו-PWA Manifest מלא.

---

## 🚀 הרצה מקומית

```bash
cd plants-care-pwa
npm install
npm run dev
```
האפליקציה תיפתח בכתובת: `http://localhost:3001`
